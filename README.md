## Project Description
This project is a console-based Community Pantry Management System developed using Java.

## Main Features
1. Register new pantry items.
2. Search for items using Item ID.
3. Register pantry requests.
4. Process requests using FIFO (First In, First Out).
5. Display request status and history.
6. Generate a low-stock report.
7. Exit the program safely.

## How to Run
1. Open the project in Eclipse.
2. Open the Main.java file.
3. Right-click inside the editor.
4. Select Run As → Java Application.
5. Follow the menu instructions in the Console.

## Data Storage
The program stores item and request information in memory while it is running. Data is not permanently saved after the program exits
